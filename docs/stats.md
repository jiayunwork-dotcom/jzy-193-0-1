# 统计口径与设计说明

本系统把「天天看、显著就停」的非正式监测，替换为**开跑前固定设计 + 按 α 消耗
函数发放停止边界**的成组序贯检验（group-sequential monitoring）。所有计算在
后端完成，双精度浮点，结果确定、可重复、可重放。

## 1. 实验设计与样本量口径

比较两组转化率 `p_A`（对照）与 `p_B`（实验），建实验时录入：

- 基线转化率 `p₁`；
- 目标转化率 `p₂`（最小可检出提升 MDE = |p₂ − p₁|，允许负向，按绝对值处理）；
- 双侧显著性水平 α；
- 功效 1 − β。

样本量采用 Fleiss《Statistical Methods for Rates and Proportions》中的
**未合并方差正态近似**（备择假设下两组方差分别估计）：

```
n = [ z_{1−α/2}·√(2·p̄·(1−p̄)) + z_{1−β}·√(p₁(1−p₁)+p₂(1−p₂)) ]² / Δ²
p̄ = (p₁+p₂)/2,  Δ = |p₂−p₁|
```

参考值：p₁=0.10、p₂=0.12、α=0.05（双侧）、power=0.80 → **每组 3841 人**。

口径差异说明（同一组输入在不同教材中可能差 1~2 人）：

- 若用零假设合并方差口径 `n = (z_{1−α/2}+z_{1−β})²·2p(1−p)/Δ²`，得 3839；
- 本系统用的 Fleiss 口径把备择假设下的两组方差分开计入，略保守，得 3841。

## 2. 检验统计量与信息时间

第 k 次查看时，累计 A/B 组访问数 `n_A,n_B`、转化数 `x_A,x_B`：

```
p̂_A = x_A/n_A, p̂_B = x_B/n_B, p̂ = (x_A+x_B)/(n_A+n_B)
z_k = (p̂_A − p̂_B) / √( p̂(1−p̂)·(1/n_A+1/n_B) )      （合并方差，零假设口径）
```

- 两组数据互换时 z 严格变号（边界对称，结论 A 胜 ↔ B 胜）。
- 信息时间（信息比例）`t_k = (n_A+n_B)/(2·n_plan)`，截断到 [0,1]。
  实际入组不等时按两组平均入组量折算；t>1 一律按 1 计算，并在返回中
  `capped=true` 标注原值。
- 边界计算中把统计量视为标准 Brownian 运动在信息时间 t 处的标准化值，
  因此任意两次查看 i,j（t_i ≤ t_j）的相关系数为
  `ρ = Cov(Z(t_i),Z(t_j)) = √(t_i/t_j)`。这正是「多次查看之间的相关性」的
  处理方式。

## 3. α 消耗规则（O'Brien-Fleming，Lan-DeMets 近似）

开跑前定死总显著性水平 α。系统当前实现一种**早期保守、后期贴近固定样本
检验**的消耗函数：

```
α*(t) = 2·( 1 − Φ( z_{1−α/2} / √t ) )       （双侧总消耗）
```

- α*(0)=0；
- α=0.05 时 **α*(0.5) ≈ 0.00557**（精确值 0.00557460…）；
- **α*(1) = 0.05 恰好**——终局一次查看就是普通固定样本检验。

## 4. 多查看停止边界怎么算（相关性如何进入）

停止边界 `c_k` 由 Lan-DeMets「消耗函数法」确定：在信息时间 t_k 处，本次新增
的第一类错误预算为 `α*(t_k) − α*(t_{k−1})`，要求在联合分布下「第 k 次查看
首次穿越 ±c_k」的概率恰好等于该增量。由于 Z(t) 是相关的 Brownian 增量，
各次穿越事件不独立，系统按相关结构逐维积分：

1. 第一次：`P_0(|Z₁| ≥ c₁) = α*(t₁)`，一维正态尾，二分反解 c₁；
2. 第 k 次：维护「此前全部未穿越」的存活密度 f(x₁,…,x_{k−1},
   均未穿越)，利用 Markov 性只保留上一维边际存活密度，条件转移
   `Z_k | Z_{k−1}=x ~ N(ρx, 1−ρ²)`（ρ=√(t_{k−1}/t_k)），对该密度做
   复合 Simpson 卷积得到本次穿越概率，二分反解 c_k；再把存活密度推进一维。
3. 二分容差 5e-13；Simpson 固定 600 个等距格点（偶数），无随机数，
   同输入按位可重复。

数值精度（α=0.05、五次等距查看 t=0.2,…,1）给出的边界：

| k | t | 累计消耗 α* | 边界 c_k |
|---|---|---|---|
| 1 | 0.2 | 0.0000117 | 4.383 |
| 2 | 0.4 | 0.001942 | 3.100 |
| 3 | 0.6 | 0.01140 | 2.553 |
| 4 | 0.8 | 0.02843 | 2.256 |
| 5 | 1.0 | 0.05000 | 2.066 |

与经典 O'Brien-Fleming 表（4.56/3.23/2.63/2.28/2.04）同档；差异来自
Lan-DeMets 消耗函数是对原始 OB 边界的连续近似（早期略保守）。数值上
Simpson 积分的联合总穿越概率等于 0.0500000；200 万次 Brownian 路径的
蒙特卡洛总穿越率 0.0498（模拟标准误约 0.00016），各阶段增量亦与消耗
预算一致。

### 数值精度声明

| 量 | 方法 | 精度 |
|---|---|---|
| 正态分位数 z_p | Acklam 有理逼近 + 一次 Halley 校正 | 绝对误差 < 1.2e-9 |
| 停止边界 c_k | 确定性复合 Simpson（600 格点）+ 二分 | 联合穿越概率绝对误差约 ≤2e-6 |
| z 统计量 / 信息时间 | float64 直接计算 | 机器精度 |
| 数据库存储 | NUMERIC(20,15) | 15 位小数，往返无损于判定 |
| 可重复性 | 全程无随机数、无浮点顺序歧义 | 同输入按位一致 |

特例：信息时间 1 处只查看一次时，边界直接取解析值
`z_{0.975} = 1.959963984540054`（返回 1.95996 量级）。

## 5. 冻结决策：已发生的查看一律冻结

**本系统采用「冻结」口径。** 一次查看一旦发生，它的信息时间、快照、
z 值、所用边界、已消耗 α 以及结论全部落库且不再被任何后续事件改写；
批次更正只影响更正之后的新查看。

为什么这样选（以及代价）：

- 不冻结的代价：一条迟到的更正批次可以**回溯改写已经宣布的上线/回滚
  结论**，审计无法自洽，且 α 账可能在更正减量后需要重算历史，破坏
  「累计消耗单调不减」的账本，甚至让同一份数据在不同时间给出互相矛盾的
  结论。
- 冻结的代价：如果早批次被大幅更正（尤其是减量更正），历史边界可能是
  在「事后看不准确」的数据上算的；冻结后该误差无法纠正，只能通过后续
  查看用新边界继续监测，必要时以新的累计证据再下一次结论（第一次结论
  保留在审计记录中）。即：**牺牲对历史结论的回溯修正，换取结论的
  不可变性与第一类错误账本的完整守恒。**
- 工程处理：更正为减量、使当前 t 低于历史查看点时，新查看的信息时间取
  历史非递减包络 `t_k = max(t_actual, t_1…t_{k−1})` 并**落库该包络值**
  （`info_fraction_used`，原始值保存在 `info_fraction_raw`），α 消耗在该
  包络上取值；t 完全没增加的相邻查看沿用上一边界、α 增量为 0。这样即便
  更正让累计样本倒退，累计 α 仍然单调不减且不超过总 α；重放时同样独立
  重算包络，与在线记录逐项一致。页面把这种查看看作「↩回落→包络值」并
  弹出明确告警。

页面与接口对更正的提示：

- 同批次号 + 同内容重复推送：返回 `duplicate_ignored`，不新增版本、
  不产生任何事件；
- 同批次号 + 不同内容：返回 `corrected`，版本号 +1，推送与更正流水
  永久保留两版；返回体带 `frozen`（实验是否已出结论）与
  `changed_since_latest_view`（当前累计是否已与最近一次查看快照不同），
  并给出明确中文提示；
- 已停止实验继续查看时，每次结果里都带「实验已在第 k 次查看冻结结论」
  的告警，新查看的越界只做监测展示，不覆盖实验级结论。

## 6. 批次、幂等与重放

- 批次以「批次号」为幂等键：同号同内容只算一次；同号不同内容即更正，
  `batches` 表保存当前生效值，`batch_versions` 表保存每次推送/更正的
  不可变流水。
- 批次事件与查看事件在各自的数据库事务内追加一行到全局 `events` 表，
  **重放严格按 events 自增序号排序**（不依赖时间戳——同事务/同微秒下
  时间戳可能打平）。重放时用截至该查看点的所有批次版本重建累计样本，
  独立重算 t、z、消耗与边界，与落库记录逐项比对（z、边界容差 1e-9，
  t 容差 1e-12，越界布尔与截断标记严格一致）。
- 全部状态在 PostgreSQL，进程无内存态；服务重启即从库恢复，重放结果
  不变。

## 7. 输入校验（422 时按字段返回原因）

- 基线/目标转化率必须严格在 (0,1)；目标率不得等于基线率；
- α、功效必须严格在 (0,1)；消耗规则目前仅 `obf`；
- 各访问数为非负整数，各转化数为非负整数且不得大于本组访问数；
- 推送给不存在的实验：422 且标出 `experiment_id`；
- 无任何数据时触发查看：409。
