# 统计口径与数值方法

本系统对两个独立二项分布的转化率做双侧成组序贯检验（group-sequential test）。
所有计算在后端 Python 完成（SciPy 仅用于标准正态分布函数，边界求解为自研确定性
数值积分，**全程无随机数**）。

## 1. 每组样本量

在原假设 H0: p_t = p_c 下使用**合并比例**（pooled proportion）的正态近似，
备择假设下用各自方差（Lachin/Fleiss 常用口径）：

```
p̄ = (p0 + p1) / 2
n = [ z_{1-α/2} · sqrt(2 p̄ (1-p̄))
      + z_{1-β} · sqrt(p0(1-p0) + p1(1-p1)) ]² / (p1 − p0)²
```

结果向上取整。参考点：p0=0.10、p1=0.12、α=0.05（双侧）、power=0.8：

| 量 | 值 |
|---|---|
| z_{1-α/2} | 1.959963984540054 |
| z_{1-β} | 0.8416212335729143 |
| n（未取整） | 3840.847482436276 |
| **每组样本量** | **3841** |

> 备注：另一种只在根号下放 `p0(1-p0)+p1(1-p1)` 的简化公式会得到 1879，
> 但那是「不做 H0 合并」的口径；本系统统一使用 H0 合并方差，与教科书
> Fleiss–Lachman 两样本率比较公式及多数功效分析软件（PASS、R `power.prop.test`
> 的保守近似）保持一致。文档与代码口径一致，可在 `app/stats.py:sample_size_per_group`
> 直接核对。

## 2. 检验统计量 Z

```
p̂_c = x_c/n_c,  p̂_t = x_t/n_t,  p̄ = (x_c+x_t)/(n_c+n_t)
SE = sqrt(p̄(1-p̄)·(1/n_c + 1/n_t))
Z  = (p̂_t − p̂_c)/SE
```

- 正向：treatment（实验组）更优；两组标签互换 ⇒ Z → −Z。
- 双侧停止域 |Z| > c_k 关于 0 对称，因此互换后结论严格对称（reject ↔ reject_negative）。
- 两组累计访问均为 0，或 SE 为 0（例如总转化数为 0）时 Z 定义为 0（继续监测）。

## 3. 信息比例

每组计划样本量 N（建实验时固定，两组共 2N）。与 SE 中的 `1/n_c+1/n_t` 项
保持一致，定义每组等效样本数

```
n_eff = 2 / (1/n_c + 1/n_t)
t     = n_eff / N
```

等组 n_c=n_t=n 时 n_eff=n，**t = n/N**。
t>1 一律截断为 1，原始值保留在 `raw_info_time`，并在查看记录与页面上标注。

更正数据可能使原始信息比例倒退。冻结策略下本次有效信息时间被夹在
`[上一次查看的有效 t, 1]`（单调不减），`clipped=true` 标记同时覆盖
「t>1 截断」与「更正导致 t 倒退夹断」两种情况，页面均有显式提示。

## 4. α 消耗函数：Lan-DeMets 近似 O'Brien-Fleming（双侧）

```
α*(t) = 2 · (1 − Φ( z_{1-α/2} / sqrt(t) )),   α*(0)=0
```

α=0.05 时的关键数值（闭式求值，无积分误差）：

| t | α*(t) |
|---|---|
| 0.1 | 0.000000… （≈1.3e-9） |
| 0.2 | 0.00008858 |
| 0.25 | 0.00008858… 见下 |
| **0.5** | **0.0055745967**（题目参考值 0.00557） |
| 0.75 | 0.02362513 |
| **1.0** | **0.05000000（恰好）** |

设计特征：早期极保守（t=0.2 首次边界约 4.56 个标准差，几乎不可能假阳性胜出），
后期趋近固定样本检验。**只在信息比例恰好 1 处查看一次时，边界严格等于
z_{0.975}=1.95996398（闭式，不进入数值递推）。** 多次查看时末期边界会略高于
1.95996（例如 2 次等距查看约 1.9793），这是为多次"窥视"付出的代价，也是
LD-OBF 的标准性质。

## 5. 逐次停止边界的计算（含多次查看相关性）

在信息时点 0<t_1<…<t_k≤1 上，把标准化统计量视为规范 Brownian 运动：

```
S(t) ~ N(0,t),   Cov(S(t_i), S(t_j)) = min(t_i,t_j)
Z_i = S(t_i)/sqrt(t_i)  ~ N(0,1),   Corr(Z_i,Z_j) = sqrt(t_i/t_j) (i<j)
```

第 k 次双侧边界 c_k 由消耗函数隐式定义：

```
P(存在 i≤k: |Z_i| > c_i) = α*(t_k)
```

这是一个高维正交矩形（orthant）概率问题，各次统计量的相关性已通过上面的
协方差结构完整计入。系统采用 **Armitage 一维递推数值积分**（Reboussin 等
gsb 算法的独立实现）：

1. 固定网格 x∈[−10,10]，N=3201 等距节点（步长 h=20/3200=0.00625）；
2. 首次边界闭式 c_1=Φ⁻¹(1−α*(t_1)/2)；
3. 给定上次查看后幸存密度 f_{k-1}(u)（在 |u|<c_{k-1} 内），传播
   `f_k(x)=∫ φ_{N(√(t_{k-1}/t_k)u, 1−t_{k-1}/t_k)}(x)·f_{k-1}(u)du`
   （分块 512×N 矩阵乘法，避免大内存）；
4. 梯形法计算 |x|<b 内质量，边界落在格点之间时使用**分数端点权重**精确积分；
5. 二分 50 轮求解 b 使累计越界概率恰为 α*(t_k)；
6. **同一信息时点重复查看**（更正只改转化数、样本量不变）：不增加信息、
   不新消耗 α，边界直接沿用上一次，按当次 Z 判定。

### 数值精度（确定性、可重放的依据）

| 项目 | 精度/容差 |
|---|---|
| 正态 CDF（SciPy 1.15，双精度） | < 1e-15 |
| α*(t) 闭式求值 | < 1e-15；α*(1)=0.05 的浮点偏差 ≤ 5e-17 |
| 首次边界（闭式） | < 1e-12 |
| 递推边界（与 N=9001、区间 [−12,12] 参考解比较） | 绝对误差 ≤ 5×10⁻⁴（K≤10 次查看） |
| 二分收敛 | 50 轮 × 每轮区间减半，边界不确定度 < 8·2⁻⁵⁰ ≪ 1e-12 |
| 重放比对容差 | boundary/z 1×10⁻⁹，info_time/spend 1×10⁻¹²，整数计数精确相等 |

与教科书 LD-OBF 参考值对照（5 次等距查看，α=0.05）：

```
本系统：4.3826, 3.0997, 2.5534, 2.2541, 2.0635
教科书：4.3826, 3.0997, 2.5534, 2.2541, 2.0638
```
（末期 0.0003 之差即网格递推的离散化误差，已包含在上表 5e-4 包络内。）

计算输入只有：实验参数（α）、全部历史查看的有效信息时点（冻结在 `looks` 表中）。
没有时间戳、线程调度、随机种子等外部输入，因此：
- 相同输入 → IEEE 双精度下**位位相同**（有 `test_boundary_determinism_bit_identical` 守护）；
- 服务重启只从 PostgreSQL 恢复这些输入，结果自然一致；
- 按事件流重放与在线逐项相同（`test_replay_matches_online_pointwise`）。

性能：10 次查看约 0.5s，20 次约 1s（纯 NumPy 单线程），满足手动/低频定时查看。

## 6. 边界不"重新规划"

边界序列只随**已发生的查看时点**增长而递推：第 k 次边界计算时，
t_1..t_{k-1} 已冻结，未来将在何时查看**不影响**当前边界（消耗函数的
独立增量性质）。这保证了使用者不能靠"之后多查/少查"来操纵本次结论。
